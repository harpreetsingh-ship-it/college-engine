Institutional Pilot Structure — Consistency Validation
Purpose

To validate whether the College Pathways Structural Evaluation Framework produces consistent structural guidance across student profiles and advisor roles within a defined pilot cohort.

This pilot evaluates reproducibility of pathway messaging, not admissions outcomes.

Pilot Scope

3–5 participating counselors (where feasible)

50–100 student evaluations

8–12 week duration

No marketing language used in sessions

No change to existing advising practices outside framework use

Pilot Design

Each participating counselor will:

Run the framework during advising sessions.

Record the structural pathway category (Band A–E equivalent).

Record primary viable pathways.

Record structural “locked” categories.

Note whether the output aligned with their independent professional judgment.

Optional:
Two counselors independently evaluate 5–10 identical anonymized profiles to test cross-counselor consistency.

Primary Metric: Structural Consistency

Measured by:

% agreement between counselor independent judgment and framework output.

% agreement between two counselors evaluating same anonymized profiles.

Stability of pathway categorization across GPA band definitions.

Target threshold (to be defined internally before pilot launch).

What Is Not Measured

Admissions success rates

Application outcomes

Time savings

Student satisfaction metrics

This pilot focuses solely on reproducibility and structural messaging alignment.

End-of-Pilot Evaluation

At conclusion:

Participating counselors provide written feedback.

Consistency metrics are compiled.

Operational friction is documented.

Go / refine / discontinue decision is documented.

No procurement discussion occurs prior to pilot review
