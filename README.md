## Wording Freeze (Phase 4)

Wording Freeze (v1): No output copy changes unless they fix a demonstrated misinterpretation observed during Phase 4 (Controlled Exposure).

Purpose: Define how Phase 4 exposure is conducted so observations are valid and non-contaminated.

Phase 4 Exposure Rules (v1)

Scope
Phase 4 is observation-only. Its purpose is to identify real-world misinterpretation and discomfort when the tool is used without explanation.

What Phase 4 is

Silent exposure

Unassisted interpretation

No iteration during exposure

Evidence gathering only

What Phase 4 is not

Not usability optimization

Not feature iteration

Not language polishing

Not institutional outreach

Not validation or persuasion

Exposure Protocol

Instruction given to users (exact text)

“Please use this tool and tell me where it felt confusing, unclear, or uncomfortable.”

No additional framing, philosophy, or reassurance may be provided.

No explanation rule

The operator must not explain outputs before or after use.

If users ask clarifying questions, they are logged verbatim and not answered during Phase 4.

No iteration rule

No changes to wording, rules, UI, or outputs are allowed during Phase 4.

All feedback is logged; none is acted upon until Phase 4 exit decision.

Eligible participants

Families or proxies are acceptable.

Prior exposure is allowed only if the interaction follows the silent protocol.

Volume target: 3–5 silent runs (not a quota, a sufficiency threshold).

Observation Discipline

During each run, the operator records:

Where users pause or reread

Which sections trigger objection or discomfort

What users think the tool is saying

What they believe the tool is optimizing for

Any assumptions about hidden boosts or discretion

Observations must be recorded before any follow-up conversation.

Feedback Classification (no fixes yet)

Each logged item is classified as one of:

Truth objection (disagreement with reality)

Language misread (wording ambiguity)

Expectation mismatch (user wanted reassurance)

UX friction (navigation or layout)

Classification does not imply action.

Phase 4 Exit Criteria

Phase 4 concludes when:

At least 3 silent runs are completed

Objection patterns (if any) are visible

A documented decision is made:

Proceed unchanged

Clarify language (specific, minimal)

Hold for structural concern

“No changes required” is a valid and acceptable outcome.

Guardrail

Phase 4 exists to protect the system from well-intentioned erosion.
No change may be justified by hypothetical users or anticipated reactions — only by observed misinterpretation.
